# LightIDS 使用说明

## 1. 运行方式

### 1.1 源码运行

进入项目根目录后执行：

```powershell
conda activate ids-lab
python -m app.main
```

源码运行需要安装依赖：

```powershell
pip install -r requirements.txt
```

### 1.2 打包程序运行

阶段七已使用 PyInstaller 生成程序：

```text
dist/LightIDS/LightIDS.exe
```

双击 `LightIDS.exe` 即可启动图形界面。

打包后的配置文件和规则文件位于：

```text
dist/LightIDS/_internal/config/config.json
dist/LightIDS/_internal/rules/default.rules
```

如果需要把程序发给别人，应发送整个目录：

```text
dist/LightIDS/
```

不要只发送 `LightIDS.exe`，因为 PyInstaller onedir 模式下还需要 `_internal` 目录中的依赖库、配置文件和规则文件。

`build/` 目录是 PyInstaller 的中间构建目录，主要保存分析结果、临时文件、警告文件和打包缓存。它不是最终交付内容。最终交付目录是：

```text
dist/LightIDS/
```

## 2. 实时抓包依赖

Windows 实时抓包依赖 Npcap。

如果需要使用网卡实时捕获功能，请先安装 Npcap：

```text
https://npcap.com/
```

如果没有安装 Npcap，离线 PCAP 导入、规则检测、阈值检测、告警筛选、统计展示和历史查询仍可作为主要演示路径使用。

## 3. 主界面功能

### 3.1 Capture 工具栏

```text
网卡选择：选择实时抓包使用的网络接口；
Advanced：显示更完整的网卡描述；
Refresh：刷新网卡列表；
Start Capture：开始实时抓包；
Stop Capture：停止实时抓包。
```

如果更换网卡后再次开始抓包，程序会询问是否清空当前会话：

```text
Yes：清空当前界面和统计后重新开始；
No：继续追加到当前结果；
Cancel：取消开始抓包。
```

### 3.2 Data 工具栏

```text
Import PCAP：导入离线 PCAP 文件；
Clear Traffic：清空当前界面、当前会话统计、规则命中数和阈值检测缓存；
Reload Rules：重新加载规则文件；
Alert filter：筛选当前告警显示；
Load History：从 SQLite 加载历史告警；
Export CSV：导出 SQLite 中符合当前筛选条件的告警；
Clear Logs：清空 SQLite alerts 表。
```

## 4. 告警筛选

程序对抓到的包或导入的 PCAP 会统一执行分析：

```text
规则匹配结果写入 rule_event；
阈值检测结果写入 threshold_alert；
两类结果都会写入 SQLite。
```

`Alert filter` 只影响界面显示和 CSV 导出，不影响检测逻辑：

```text
All alerts：显示所有告警；
Rule events：只显示规则事件；
Threshold alerts：只显示阈值告警。
```

一般来说：

```text
rule_event 适合展示规则引擎命中情况；
threshold_alert 更适合展示垂直端口扫描、横向扫描、ICMP 高频等阶段六行为检测结果。
```

## 5. 历史数据说明

SQLite 数据库保存历史告警，不保存完整 PCAP 文件，也不保存所有普通流量包。

当前数据库主要保存：

```text
alert_type；
severity；
message；
src_ip；
dst_ip；
protocol；
created_at。
```

`Clear Traffic` 和 `Clear Logs` 的区别：

```text
Clear Traffic：只清空当前界面和当前会话状态，不删除数据库历史告警；
Clear Logs：清空 SQLite alerts 表，删除历史告警记录。
```

导入大 PCAP 时，界面只保留最近一部分流量和告警用于展示，但 SQLite 会保存完整告警结果。CSV 导出直接查询 SQLite，不受界面显示上限影响。

## 6. 阶段六测试 PCAP

可以生成阶段六专用测试 PCAP：

```powershell
conda activate ids-lab
python tools/generate_stage6_pcaps.py
```

生成目录：

```text
data/stage6_pcaps/
```

推荐演示顺序：

```text
1. 点击 Clear Logs，清空历史告警；
2. 导入 tcp_syn_scan_positive.pcap，观察垂直端口扫描 threshold_alert；
3. 点击 Clear Traffic；
4. 导入 tcp_horizontal_scan_positive.pcap，观察横向扫描 threshold_alert；
5. 点击 Clear Traffic；
6. 导入 dns_response_negative.pcap，确认 DNS 响应不会误报端口扫描；
7. 点击 Clear Traffic；
8. 导入 icmp_request_positive.pcap，观察 ICMP 高频 threshold_alert；
9. 使用 Alert filter 切换 All alerts / Threshold alerts；
10. 使用 Export CSV 导出检测结果。
```

